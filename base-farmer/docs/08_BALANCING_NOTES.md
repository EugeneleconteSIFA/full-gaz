# Balancing Notes

This document is intentionally provisional.

Do not treat these values as final.

## Initial target values

### Match
- duration: 420 seconds
- opening: 60 seconds
- normal production: every 60 seconds
- endgame starts: 300 seconds
- endgame production: every 30 seconds
- bases: 7

### Capture
- neutral capture target: 3 seconds
- enemy flip target: 3 seconds
- contested: no progress

### Character design
Use relative differences first, not absolute balance perfection.

Suggested starting relationships:

Robust:
- HP: 140%

- range: 90%
- damage: 100%

## Balance questions to test

1. Can the first captured bases snowball too easily?
2. Is the fast character overwhelmingly dominant?
3. Can a defender hold a base forever?
4. Is ranged combat frustrating?
5. Does dying feel too punitive?
6. Do resources meaningfully change decisions?
7. Is the endgame actually more exciting?
8. Can the losing team still recover?
9. Is there a reason to contest rather than retreat?
10. Does every character have a credible path to victory?

Do not solve these by adding mechanics immediately. First measure and adjust numbers.
